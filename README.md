💳 Cash Book Pro - Multi-Account Ledger (PWA)
Cash Book Pro ek modern, fast, aur installable Progressive Web App (PWA) hai jo aapke roozmarrah ke maali hisab kitab (Cash In / Cash Out) ko asaani se manage karne ke liye banayi gayi hai. Isme multi-account ledger, analytics charts, dark/light themes, recycle bin, aur offline access jaise powerful features shamil hain.
🌟 Key Features
💼 Multi-Account Support: Aik se zyada accounts banayein (e.g., Main Cash, Personal, Business) aur aasani se switch karein.
📈 Cash In / Cash Out: Fast and simple entry recording with real-time balance calculations.
🔍 Advanced Search & Filtering: Name, details, amount, date range, aur account scope ke mutabiq search karein.
📊 Analytics & Charts: Interactive daily/weekly transaction breakdown.
🎨 Multiple Color Themes: Dark, Light, Blue, Green, Purple, Orange, aur Pink themes.
🗑️ Recycle Bin (Trash): Deleted entries ya accounts ko restore karein ya permanently delete karein.
📥 Import & Export:
Full JSON backup export & restore.
Printable/Downloadable HTML Financial Statements.
📱 Offline PWA Support: Internet ke baghair bhi mukammal kaam karti hai.
