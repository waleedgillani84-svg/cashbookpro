💳 Cash Book Pro — Multi-Account Ledger & Cash Flow Manager
​Cash Book Pro is a modern, responsive, offline-first Progressive Web Application (PWA) designed to track multi-account cash flow, income, and expenses effortlessly across mobile and desktop devices.

​🚀 Key Features
​🏛️ Multi-Account Support: Manage multiple accounts (e.g., Main Cash, Personal, Business, Bank) and switch between them seamlessly.
​📱 Offline-First PWA: Built with Service Workers and IndexedDB (with LocalStorage fallback) so your financial data is accessible even without an internet connection.
​📈 Fast Cash Flow Logging: Add + CASH IN and - CASH OUT entries with auto-saved timestamps and smart remark suggestions.
​📊 Interactive Analytics: Visualize income vs. expense cash flow using interactive Chart.js graphs.
​🎨 Dynamic Color Themes: Personalize the app with themes including Emerald Mint, Ocean Sapphire, Royal Amethyst, Sunset Ruby, Golden Amber, and OLED Onyx.
​🔍 Advanced Search & Filters: Search transactions by keyword, specific date, transaction type, or filter across all accounts.
​🗑️ Recycle Bin (Trash): Safely delete transactions with options to restore or permanently erase them.
​📄 Statement Export & Sharing:
​Export statements to PDF or PNG.
​Direct 1-tap sharing to WhatsApp.
​💾 Data Backup & Restore: Full JSON data export and import capabilities for easy backup and cross-device transfer.
​🛠️ Tech Stack
​Frontend Framework: Alpine.js
​Styling: Tailwind CSS
​Charts: Chart.js
​Document Export: html2canvas & jsPDF
​Storage: IndexedDB & LocalStorage
​PWA Capabilities: Web App Manifest (manifest.json) & Custom Service Worker (sw.js)
